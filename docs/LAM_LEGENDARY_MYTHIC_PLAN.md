# Living Archive Special Palette

The previous 40 one-of-one legendary/mythic machine visual pass has been removed.

Only the reusable background/material color palette is kept:

- `config/lam_special_backgrounds.json`

`npm run lam:specials` no longer generates special machine layouts or preview pages. It only checks and normalizes the retained palette so those colors can later be mixed into the normal trait randomizer.
