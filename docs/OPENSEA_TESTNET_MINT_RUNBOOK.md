# Living Archive Machines OpenSea Testnet Mint Runbook

This runbook is only for the new `LivingArchiveMachines` collection.
Do not use `MechanicalCanvas.sol` for the 5555 LAM mint.

## OpenSea Rules We Need To Satisfy

- Token metadata must be reachable from `tokenURI`.
- This project now returns `ipfs://METADATA_CID/{tokenId}.json`.
- Token metadata should include `image`, `animation_url`, `external_url`, and `attributes`.
- Collection metadata is served from `contractURI`.
- OpenSea testnet review happens through `https://testnets.opensea.io/`.

Official references:

- https://docs.opensea.io/docs/metadata-standards
- https://docs.opensea.io/docs/contract-level-metadata
- https://testnets.opensea.io/

## Current Local State

- Supply metadata exists for 5555 tokens in `build/metadata`.
- Current review images are partial, not final full supply.
- Current animations are partial, enough for a small Sepolia test mint.
- `build/contract/contract.json` is generated by `npm run lam:contract-metadata`.
- Strict OpenSea validation will fail until real CIDs and final website/API URLs replace placeholders.

## Safe Sepolia Test Mint Flow

1. Generate or refresh the new LAM data:

```powershell
npm run lam:collection
npm run lam:layouts
npm run lam:metadata
npm run lam:contract-metadata
```

2. Upload only the media you want to test first.

For Pinata direct folder upload:

```powershell
$env:UPLOAD_PATH="build/images"; $env:PINATA_NAME="lam-test-images"; npm run lam:upload:pinata
$env:UPLOAD_PATH="build/animations"; $env:PINATA_NAME="lam-test-animations"; npm run lam:upload:pinata
```

For local CAR files:

```powershell
npm run lam:car:images
npm run lam:car:animations
```

3. Regenerate metadata with the real CIDs:

```powershell
$env:IMAGE_BASE_URI="ipfs://IMAGE_CID_FROM_UPLOAD"
$env:ANIMATION_BASE_URI="ipfs://ANIMATION_CID_FROM_UPLOAD"
$env:EXTERNAL_BASE_URL="https://YOUR_SITE/archive"
$env:CUSTOM_STATE_BASE_URI="https://YOUR_SITE/lam"
$env:PART_MANIFEST_URI="ipfs://PART_MANIFEST_CID/part-manifest.json"
$env:PALETTE_MANIFEST_URI="ipfs://PALETTE_MANIFEST_CID/lam_special_backgrounds.json"
npm run lam:metadata
```

4. Upload metadata and contract metadata:

```powershell
$env:UPLOAD_PATH="build/metadata"; $env:PINATA_NAME="lam-test-metadata"; npm run lam:upload:pinata
$env:UPLOAD_PATH="build/contract"; $env:PINATA_NAME="lam-test-contract"; npm run lam:upload:pinata
```

Or create CAR files:

```powershell
npm run lam:car:metadata
npm run lam:car:contract
```

5. Validate before deploy:

```powershell
$env:LAM_TEST_MINT_COUNT="5"
npm run lam:validate-opensea
```

For placeholder-friendly local testing only:

```powershell
$env:LAM_OPENSEA_STRICT="0"; $env:LAM_TEST_MINT_COUNT="5"; npm run lam:validate-opensea
```

6. Deploy the new LAM contract to Sepolia:

```powershell
$env:LAM_BASE_URI="ipfs://METADATA_CID_FROM_UPLOAD/"
$env:LAM_CONTRACT_URI="ipfs://CONTRACT_CID_FROM_UPLOAD/contract.json"
$env:LAM_MINT_PRICE_ETH="0.03"
npm run lam:deploy:sepolia
```

The deploy script writes:

```text
build/deployments/living-archive-sepolia.json
```

7. Mint test tokens:

```powershell
$env:LAM_CONTRACT_ADDRESS="0xDEPLOYED_CONTRACT"
$env:LAM_MINT_TO="0xYOUR_TEST_WALLET"
$env:LAM_MINT_QUANTITY="3"
npm run lam:mint:test
```

8. Check OpenSea testnet:

```text
https://testnets.opensea.io/assets/sepolia/0xDEPLOYED_CONTRACT/1
```

## Before Mainnet

- Replace all placeholder CIDs and example URLs.
- Set the real royalty recipient.
- Decide whether public mint should be enabled immediately or only after owner/admin test mints.
