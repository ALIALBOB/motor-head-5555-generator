## Collection Description

MotorHeads is a 5,555-piece Ethereum collection of interactive living archive machines. Each MotorHead is built from mechanical canvas parts: machine heads, chassis plates, clothes, bags, counters, scars, cores, gears, fluids, and strange wearable mechanisms.

Every NFT includes a static image and an interactive animation. Open the animation to dismantle, drag, assemble, and start or stop the machine motion.

The base DNA of every MotorHead is locked at mint. Future owner customization, awaken state, added parts, holder-bond evolution, transfer scars, sale counters, and agent-style profiles are planned as an overlay layer through the future MotorHeads website.

No burn. No reroll. The machine you mint is the machine you own.

## Mint Page Sections

### Section 1: Interactive Machines

MotorHeads are built to be touched. Each NFT includes an animation page with a small assembly system: dismantle the machine, drag the parts back into place, then start the motion.

There are 55 full-gold MotorHeads in the 5,555 supply. The first 10 are treasury mints. The remaining 45 are hidden lucky mints distributed through the collection.

### Section 3: Old Holder GTD

Current holders of the previous 333-piece archive collection receive GTD access. The holder snapshot found 96 current wallets.

### Section 4: Alive Roadmap

The base NFT is permanent. The future alive layer is planned to let owners connect a wallet, awaken a MotorHead, customize visual overlays, add parts, and evolve the machine through wallet history.
