LOOT TABLE — what crates drop

The parts catalog for a crate tier. Weights set the odds (higher = more common). Setting a new table writes a new immutable version; in-flight opens keep the version they snapshotted.

DISTRIBUTE CRATES — the reward

Mint crates to a holder's wallet (they open them from their Garage). This is how you hand out crate rewards.

CRATE AIRDROP — Merkle claim (all holders)

The CrateDistributor lets every holder claim their own crate from the Garage (they pay their own gas), so you don't mint 1,465 times. Two one-time setup taps: grant it MINTER, then publish the snapshot root.

Do these two once. Re-run the snapshot + Set root again if the holder set changes before public launch.

EFFECT ITEM METADATA

Sets the ScrapParts base URI so the won effects (Neon / Holo / Teal) show their name + card art in wallets and on the ScrapParts collection page. One-time. The {id} is required — it's substituted per token.

AIRDROP TO GARAGES — reward each NFT directly

Every MotorHead owns a wallet (its garage). This sends ETH or an NFT straight into that wallet, so the reward is bound to the specific NFT — separate from the shared pool, and it travels with the NFT when sold. The holder controls it. (All 5,555 garage addresses are saved in Downloads/motorheads-garages.csv.)

ETH → garages

⚠️ Sends one transaction per garage (a MetaMask confirm each) — ideal for a handful of winners. For hundreds/all, use the CSV with a disperse tool (one tx, many recipients).

NFT → a garage

Sends one NFT you own — from another collection or a MotorHead — into the target MotorHead's garage.

REWARD POOL (ETH split)

The shared-pool model: deposit ETH and it splits equally across all NFTs; holders pull-claim their share. Different from Airdrop-to-Garages above (which targets specific NFTs). Keep the balance modest — deposit near payout time.

🎁 NFT rewards (other collections or MotorHeads): the pool is ETH-only. To reward an NFT, send it directly to the winner's wallet — or their garage address (shown per machine on the Garage page). A raffle/airdrop helper can be added later if you want it on-chain.

FEES & TREASURY

Activation fees collect here until swept to the treasury. Anyone can trigger the sweep, but funds only ever go to the treasury address.

CONTROLS

Emergency pause halts activate + open. Grant a backend the MINTER role to auto-distribute crates (e.g. for X-post rewards).

CRATE SIGNER (authorizes holder crate-opens)

Rotates the key the backend signs crate-opens with (prefilled with the deployed backend signer). Until you set this, your main wallet is the on-chain signer and holders can't open their own crates via the backend.
